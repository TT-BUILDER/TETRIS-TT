# 内部変数（settingオブジェクト）解説
## １．そもそもsettingとは
> ゲーム全体の設定をつかさどるヤツ。値を少しいじれば簡単に狂う。
## ２．管理品目（プロパティ一覧）
> *object*や*Array*と表記しているものはすべて記述するととても見づらくなるので省略している。
> 中身を確認したい場合は実際のソースコードを確認してね。
> |略記方式|意味|
> |-|:-:|
> |*Array* of *type*|*type*の配列|
> |*Array*|配列。中身は混ぜこぜかもしれない。|
> |*Object*|オブジェクト（インスタンスではない。連想配列。）|
>### 画面管理系統
>>- scHeightTile
>> デフォルト値：18\
>> テトリスをする盤面の横幅タイル数。
>>- scWidthTile
>> デフォルト値：10\
>> テトリスをする盤面の縦幅タイル数。
>>- scTileSize
>> デフォルト値：16\
>> １タイル当たりの大きさ。
>>- scScaleMult
>> デフォルト値：2\
>> スクリーン全体の拡大率。
>>- scBGcolor
>> デフォルト値："rgb(0,0,0)"\
>> 背景色。
>>- scBGgridColor
>> デフォルト値："rgb(255,255,255,0.5)"\
>> 格子線の色。アルファ値（不透明度）が0.5なので半透明になる
>>- scBGgridWidth
>> デフォルト値：1\
>> 格子線の幅（太さ）。ピクセル単位で設定する。
>>- isBGimage
>> デフォルト値：false\
>> 背景に画像を使用するかどうかのフラグ。falseで使用しない。
>### 画面表示系統
>>- BGimageSource
>> デフォルト値：null\
>> 画像のエレメントIDの配列にすることで読み込んでくれるようになる。
>>- gameOverSprash
>> デフォルト値：*Array* of *Object*\
>> ゲームオーバー時のメッセージをオブジェクトの配列で管理する。\
>> オブジェクトの構造は{ str : < string > , size : < number > }となっている。
>>- pauseSprash
>> デフォルト値：*Array* of *Object*\
>> ポーズ時のメッセージをオブジェクトの配列で管理する。\
>> オブジェクトの構造は{ str : < string > , size : < number > }となっている。
>>- shape 
>> デフォルト値：*Array* of *Array* of *Array* of *Number*\
>> 略記が大変ややこしくなっているが、二次元ベクトルをまとめた二次元配列をまとめた三次元配列である。\
>> （おそらくこの文章よりもソースコードを見たほうが圧倒的に早い。）\
>> テトリミノの形を決定する重要なプロパティである。
>>- kindOfShape
>> デフォルト値：7\
>> テトリミノの種類数。\
>> 明示的に数値リテラルを書き込んでいるだけで後からshape配列の長さに書き換わる。
>>- nextListLength
>> デフォルト値：7\
>> ネクスト表示のバッファの長さを決める。
>> kindOfShapeよりも少ない数値になるとネクストが完全なランダム生成になる（理不尽化する）
>>- showingNextListLength
>> デフォルト値：6\
>> 画面に表示するネクストの個数。
>>- scoreDigit
>> デフォルト値：6\
>> スコア、ハイスコア、ライン数、レベルなどの数値表示の桁数。
>>- stringsColor
>> デフォルト値："rgb(0,224,224)"\
>> 「NEXT:」の文字の色。
>>- stringSize
>> デフォルト値：16\
>> 「NEXT:」の文字の大きさ。\
>> 後で勝手にscTileSizeに書き換わる。
>### その他
>>- SRSlist
>> デフォルト値：*Array* of *Array* of *Number*\
>> SRS（スーパーローテーションシステム）に使用する二次元ベクトルの配列。\
>> この配列のおかげでプレイしやすくなっている。
>>- SRSlistForI
>> デフォルト値：*Array* of *Array* of *Number*\
>> Iミノ専用のSRS（スーパーローテーションシステム）に使用する二次元ベクトルの配列。\
